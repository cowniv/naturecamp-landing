# 10 · NatureCamp Landing Page

**Roadmap stage:** Phase 4 – UI/UX to Code · October 2024
**Design:** my own Figma design (*Portfolio-Projects → Project 1: NatureCamp*)

![design](../_design-refs/naturecamp.png)

A summer camp landing page I designed in Figma and then built pixel-close in HTML, CSS and JS.

### Features
- Glassy pill navigation with a Registration dropdown
- 3-column hero (copy · character · CTA) that stacks on mobile
- Fluid type with `clamp()`
- Staggered reveal animation on load

### Assets
Export the 3D camper character from Figma as a PNG with a transparent background and save it as `assets/camper.png`.

### What I practiced
- Turning a Figma frame into code: spacing, type scale, color tokens
- CSS Grid for asymmetric layouts
- Accessible dropdowns (`aria-expanded`, click-outside to close)
